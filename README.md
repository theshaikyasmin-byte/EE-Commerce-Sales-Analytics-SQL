# E-Commerce Sales Analytics – SQL Project

## Project Overview

This project analyzes e-commerce customer and order data using SQL Server.

## Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Database Tables

### Customers
Contains customer information such as:
- Customer ID
- Customer Name
- City
- State

### Orders
Contains order information such as:
- Order ID
- Customer ID
- Order Date
- Order Status
- Total Amount

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- RANK
- DENSE_RANK
- ROW_NUMBER
- LAG
- LEAD

## Project Objectives

- Analyze customer information
- Analyze order information
- Calculate sales and order totals
- Understand customer purchasing activity
- Practice SQL JOINs and aggregate functions
- Use window functions for data analysis
